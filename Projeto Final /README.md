# 🚗 Projeto de Análise Exploratória e Previsão de Preços de Carros Usados

Este repositório contém o projeto prático individual desenvolvido como requisito avaliativo para a disciplina do semestre.

## 📋 Contexto do Projeto e Escolha do Tema
O mercado de carros usados é altamente dinâmico e influenciado por múltiplos fatores. O objetivo deste projeto é analisar uma base de dados automotiva para compreender quais variáveis (como quilometragem, ano e tipo de combustível) mais impactam o valor de revenda de um veículo. 

Além disso, foi desenvolvido um modelo de Machine Learning (Regressão Linear) capaz de estimar o preço de venda justo (`Selling_Price`) de um automóvel com base em suas características técnicas.

## 📂 Estrutura das Pastas
* `/data`: Pasta que armazena a base de dados original (`car data.csv`).
* `projeto_final.ipynb`: Notebook principal contendo toda a análise estatística, gráficos e o treinamento do modelo preditivo.
